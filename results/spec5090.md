## Supplemental full-model E2E on RTX PRO 6000

Ouro-1.4B ran on GPU 1 of a two-card RTX PRO 6000 Blackwell Server Edition instance using its preinstalled `/venv/main` (PyTorch 2.13.0+cu130). Each arm generated 64 tokens for the same prompts. All γ=1/2/4 outputs and exit depths matched γ=0 exactly. Times are medians of three alternating trials after warmup; they include prefill, proposal, verification, and KV commit. A separate benchmark used GPU 0 during part of the run, so host-level contention may affect timings. These measurements are not RTX 5090 results.
