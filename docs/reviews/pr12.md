# PR12 review follow-up

The NUMA test now installs its simulated Linux affinity function even on platforms where `os.sched_getaffinity` does not exist. Validation: 21 targeted A/B-schema CPU tests passed with CUDA blocked; Ruff passed. The actual GPU benchmark remains Linux/scheduler-specific.

The model/cache call site and standalone write adapter now spell out the traversal contract, validation ordering and full-descriptor cost. The private descriptor is intentionally an internal ownership lease shared by model/cache/runner, not a stable user API. A public facade and a cheaper standalone-write path are deferred API/performance changes: no production hot-path caller uses that standalone adapter, and adding aliases would not remove its lifecycle obligations. The original M2 measured code and 20–21% W1 evidence remain unchanged by these comments/test changes.
