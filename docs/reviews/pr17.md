The canonical result is [q2-external-final-qualification.json](evidence/q2-external-final-qualification.json). It is a versioned final decision layer: `generation_equivalence=passed`, `timing_controls=invalid`, `performance_qualification=inconclusive`, `passed=false`, and `supersedes` binds the original report SHA256. The [chronology](evidence/q2-external-chronology.json) is preserved byte-for-byte. The final decision supersedes timing qualification only; it never overwrites the historical raw report or infers a causal slowdown amount.

`vllm_lt/benchmarks/q2_external_qualification.py` runs directly with the standard library. It checks report/chronology identity, the recorded N2 artifact bindings, overlapping file chronology and reviewed shared affinity before emitting a new, exclusively created record. It cannot turn contaminated timings into a qualified result. It consumes reviewed evidence; it is not a substitute for the raw auditor or a future positive control audit.

Seven new tests cover contamination despite matching tokens, source/case hash mismatch, chronology outside N2, invalid status/affinity, and failed generation subchecks.
