## Run order and acceptance

Exactly 105 executions in eight sequential fresh processes: N-A, N-B, A1, B1,
B2, A2, P-A, P-B. Each process loads the model once; each row gets a fresh
engine, preserving allocator/compiler state within the process. No shared
caches are dropped. Downloads, loading, warmups and profiles are excluded from
delivery timing. All runs use the existing M1 inference executor and boundaries.

- N-A/N-B: seven feasibility cells each; five oracle and eleven native
  numerical executions in A, eleven native executions in B.
- A1/B1/B2/A2: seven warmup cells followed by seven measured cells per process.
- P-A/P-B: W1/W4 warmups followed by W1/W4 profiles, excluded from timing.

Cells: W1/refill, W2/refill, W3/refill, W4/refill, W4/no-refill,
W5/refill, W5/no-refill. Both matched pairs must pass individually:

- W1 generated-token throughput B/A ≥ 1.10.
- Each of six control-cell observations B/A ≥ 0.95.
- W1 minimum B must strictly exceed maximum A; overlap is inconclusive.
- Peak allocated and reserved GPU memory increases each ≤ 67,108,864 bytes.
- Engine setup increase ≤ 100,000,000 ns.
- Exact measured token/depth/gate/work histories and fixed 6 GiB KV pool.
- All 51 numerical comparisons pass original FP32 logit/discrete gates;
  the 17 B/A streams additionally require exact selected boundaries and populated KV.

The original Q1 subset is L16-F0, L256-F0, L64-F2, L128-F3, plus actual live
gates on L16-F0 (threshold 0.7, minimum 2, maximum 4). Each records nine genuine
predictions from eight supplied continuation inputs. Forced fixtures cover
adjacent shallow/deep exits; packed execution covers refill and no-refill.
The numerical pool is 160 pages of 16 tokens, chunk size 64, at most four requests.
The two preselected FP32 exact-comparison dump fixtures are L64-F2 and L256-F0.

No retries or extra trials. Execution/numerical/nonfinite/control/ownership,
cleanup or budget failures stop subsequent workers. Finite performance misses
complete the planned evidence matrix and cannot qualify the optimization.
Two measured observations provide ranges, not statistical confidence.
