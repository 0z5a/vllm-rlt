# BF16 serving compatibility — 2026-09-12

On one scheduler-reserved NVIDIA L20X, the first inference after readiness and
three overlapping requests matched direct engine execution for text, token
counts and finish reasons. These four cases included fixed and adaptive depth.
The unmodified vLLM 0.28.0 client then passed all three planned workloads:

| Workload | Concurrency | Requests/s setting | Successful / failed | Input / output tokens | ITL samples per response |
| --- | --- | --- | --- | --- | --- |
| Serial | 1 | infinite | 16 / 0 | 2,048 / 256 | 15 |
| Concurrent | 8 | infinite | 16 / 0 | 2,048 / 256 | 15 |
| Finite rate | 4 | 2 | 16 / 0 | 2,048 / 256 | 15 |

Each response generated 16 tokens with exactly 15 ITL samples: terminal and
usage events did not add timing samples. Client errors were empty, and recorded
TTFT/ITL values were finite and nonnegative. These are single-pass compatibility
observations, not a speedup or tail-latency qualification.

The device run used clean source `355ba4e3c99914d409e2154ee579dfb06f039840`,
PyTorch 2.13.0, BF16 weights/KV, Triton attention, and Ouro model/tokenizer revision
`574fa66cb8bf5abdc979642d01cf2b79b16bfab1`. One resident server used 512 KV blocks
of size 16, sequence limit 8, token budget 128, refill scheduling, CPU affinity
0–7 and one intra-op thread. The client CLI, benchmark driver and request parser
matched release tag commit `2cf0a6915ce544dc493a0990f2ea38d81601128a` byte-for-byte;
external client plugins were disabled. No shared cache was cleared.

Preparation and startup were separate from client timings. The first actual
inference preceded benchmark probes; each client then performed its own initial
test request. No additional warmups or retries ran. Later Unicode validation,
termination logging and assertion changes passed CPU checks; the device evidence
remains tied to its recorded commit. The worker, scheduler and normal stream
framing were unchanged. The final CPU suite passed 208 tests with 23 GPU/optional
cases skipped, and Ruff lint/format checks passed.

The server logged zero remaining requests and KV blocks. Both task-owned
processes exited, and the scheduler released the reservation.
