# Public artifact copies

Only necessary test configuration and scientific results are public: GPU model/count/memory, software versions, precision, shapes, batch/concurrency, timings, numerical errors and retained failures.

Cluster identities, access routes, accounts, filesystem paths, process identifiers and resource-lock identifiers are omitted. Complete original evidence remains in private storage. Historical record hashes refer to those originals unless explicitly identified as public-copy hashes. Redacted orchestration excerpts are documentation, not byte-identical executed sources or runnable deployment configuration. Scientific measurements and acceptance thresholds are unchanged.

The Thor subdirectory provides a separate manifest for its public copies and distinguishes private-original PTX hashes from public PTX hashes. No new GPU measurement or complete-model result is introduced by this publication change.
